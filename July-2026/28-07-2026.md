so once i find "a" , i check for b from index of a+1 (i kinda slice the first part of t until a)
so if b was before a (then order would be wrong) , b will not be found

came up with this after some logic fixes and dry runs - 

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        int previousFound = -1;
        int i = 0;
        for (i = 0;i<s.length();i++) {
            char c = s.charAt(i);
            int j = previousFound+1;
            for (j = previousFound+1;j<t.length();j++) {
                if (t.charAt(j) == s.charAt(i)) {
                    previousFound = j;
                    break;
                }
            }
            if (j == t.length()) {
                return false;
            }
        }
        if (i != s.length()) {
                return false;
            }
        return true;
    }
}
```

class Solution {
    public boolean isSubsequence(String s, String t) {
        int i = 0;
        int j = 0;
        while(i<s.length() && j<t.length()){
            if(s.charAt(i) == t.charAt(j)){
                i++;
            }
            j++;
        }
        return i == s.length();
    }
}

loop through elements , consider each element as pivot (while keeping track of leftsum) and using another loop , calculate right sum of assumed pivot

```java
class Solution {
    public int pivotIndex(int[] nums) {
        for (int i = 0;i<nums.length;i++) {
            int assumedPivotIndex = i;
            int leftSum = 0;
            int rightSum = 0;
            for (int j = 0; j<nums.length;j++) {
                if (j < i) {
                    leftSum = leftSum+ nums[j];
                }
                else if (j>i) {
                    rightSum = rightSum+ nums[j];
                }
            }
            if (leftSum == rightSum) {
                return assumedPivotIndex;
            }
        }
        return -1;
    }
}
```

class Solution {
    public int pivotIndex(int[] nums) {
        int[] sumArray = new int[nums.length];
        int sum = 0;
        for (int i =0;i<nums.length;i++) {
            sum = sum + nums[i];
            sumArray[i] = sum;
        }
        sum = 0;
        for (int j =0;j<nums.length;j++) {
            if (sum == (sumArray[nums.length-1] - sumArray[j]) ) {
                return j;
            }
            sum = sum + nums[j];
        }
        return -1;
    }
}

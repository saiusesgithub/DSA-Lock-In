### 1464. Maximum Product of Two Elements in an Array (POTD - 27/07/2026)
Easy

started simple , thought i had to return max product but turns out instead of max1 * max 2
i had to return (max1-1) * (max2-1)

so initially came up with brute force method - 

```java
class Solution {
    public int maxProduct(int[] nums) {
        int max = 0;
        for (int i =0;i<nums.length;i++) {
            for (int j = i;j<nums.length;j++) {
                if (i != j) {
                if ( ((nums[i]-1) * (nums[j]-1)) > max) {
                    max = (nums[i]-1) * (nums[j]-1);
                } }
            }
        }
        return max;
    }
}
```

```java
class Solution {
    public int maxProduct(int[] nums) {
        int max1Index = 0;
        int max2Index = 1;
        for (int i =1;i<nums.length;i++) {
            if (nums[i] >= nums[max1Index]) {
                max2Index = max1Index;
                max1Index = i;
            }
            else if (nums[i] < nums[max1Index] && nums[i] > nums[max2Index]) {
                max2Index = i;
            }
        }
        return (nums[max1Index]-1)*(nums[max2Index]-1);
    }
}
```

fixed that -
```java
class Solution {
    public int lengthOfLastWord(String s) {
        int count = 0;
        boolean wordStarted = false;
        for (int i = s.length()-1 ; i>=0 ; i--) {
            if (s.charAt(i) == ' ' && wordStarted == false) {
                continue;
            }
            wordStarted = true;

            if (s.charAt(i) == ' ') {
                return count;
            }
            else {
                count++;
            }
        }
        return count;
    }
}
```

int[] sorted = nums;

What does this do?

It doesn't make a copy.

sorted = [1,2,5,6]

So you've accidentally destroyed the original input.

class Solution {

and chatgpt also said - 

Your original flag idea is almost the optimal solution.

You correctly count places where the sorted order breaks:
nums[i] > nums[i + 1]

But you only compare adjacent elements from index 0 to n - 1.

A rotated array is circular, so you are missing one final comparison:

last element → first element

consider:

[2, 1, 3, 4]
Inside the array:
2 > 1
But circularly, also compare:
4 > 2

That gives two breaks, so invalid.

Tiny implementation hint:

Instead of looping only until nums.length - 1, compare every index with the next circular index:

nums[(i + 1) % nums.length]

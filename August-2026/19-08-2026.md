### 191. Number of 1 Bits
Easy

didnt know how to do it with bit manipulation so tried this initially - 

```java
class Solution {
    public int hammingWeight(int n) {
        int count = 0;
        String s = Integer.toBinaryString(n);
        for (int i =0;i<s.length();i++) {
            if (s.charAt(i) == '1') {
                count++;
            }
        }
        return count;
        
    }
}
```

and asked chatgpt for a hint and it said - 

a Java int is 32 bits, the simplest approach is - Check all 32 bit positions.

OHH , i never thought of the size of int , i thought of the entire approach on my own , except this looping part 

so implemented this - 

```java
class Solution {
    public int hammingWeight(int n) {
        int count = 0;
        for (int i =0;i<32;i++) {
            int mask = 1 << i;
            if ((n & mask) != 0) {
                count++;
            }
        }
        return count;
    }
}
```

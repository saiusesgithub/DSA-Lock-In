### 342. Power of Four
Easy

```java
class Solution {
    public boolean isPowerOfFour(int n) {
        if (n < 4 && n != 1) {
            return false;
        }
        int andResult = n & n-1;
        if (andResult!=0) {
            return false;
        }
        int setMask = n & -n;
        boolean countZeroes = false;
        int count = 0;
        for (int i =31;i>=0;i--) {
            int mask = 1 << i;
            if ((n&mask) != 0) {
                countZeroes = true;
                continue;
            }
            if (countZeroes) {
                count++;
            }
        }
        System.out.println(count);
        if (count % 2 !=0) {
            return false;
        }

        return true;
    }
}
```

8  → NOT power of 4

so we need some other check , and found out that - 

all powers of 4 have - even number of zeroes AFTER the set bit
non powers of 4 have - odd number of zeroes AFTER the set bit

---

so basically 

Power of 2 - Exactly one set bit.


Power of 4 - Exactly one set bit
AND
that set bit occurs at an even position / even number of trailing zeroes

Examples - 

1  = 1       → position 0 → YES
2  = 10      → position 1 → NO
4  = 100     → position 2 → YES
8  = 1000    → position 3 → NO
16 = 10000   → position 4 → YES
32 = 100000  → position 5 → NO
64 = 1000000 → position 6 → YES

## Problem 1 - 

### 2114. Maximum Number of Words Found in Sentences

```java
class Solution {
    public int mostWordsFound(String[] sentences) {
        int maxCount = 0;
        for (String s : sentences) {
            int count = 1;
            for (int i =0;i<s.length();i++) {
                if (s.charAt(i) == ' ') {
                    count++;
                }
            }
            if (count > maxCount) {
                maxCount = count;
            }
        }
        return maxCount;
    }
}
```

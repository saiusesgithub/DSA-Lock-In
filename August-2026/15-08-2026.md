### 938. Range Sum of BST
Easy

initially misunderstood the problem and implemented this - 

```java
class Solution {
    public int rangeSumBST(TreeNode root, int low, int high) {
        if (root == null) {
            return 0;
        }
        int sum =0;
        if (root.left.val > low) {
            sum += rangeSumBST(root.left,low,high);
        }

            sum += rangeSumBST(root.right,low,high);
        }
        sum += root.val;
        return sum;      
    }
}
```

then after reading the question and understanding it properly , took out pen and paper and dry ran / visualised the code then came up with this - 
```java
class Solution {
    public int rangeSumBST(TreeNode root, int low, int high) {
        if (root == null) {
            return 0;
        }
        int sum = 0;
        sum += rangeSumBST(root.left,low,high);
        sum += rangeSumBST(root.right,low,high);

        if (root.val >= low && root.val <= high) {
            return sum+root.val;
        }
        else {
            return sum+0;
        }  
    }
}
```

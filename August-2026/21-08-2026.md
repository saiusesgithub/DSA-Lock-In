## Problem 1 - 

### 476. Number Complement
Easy

on first glance , felt very easy like one line solution (return ~int (NOT OPERATOR))

but then the description said - 
Input: num = 5
Output: 2
Explanation: The binary representation of 5 is 101 (no leading zero bits), and its complement is 010. So you need to output 2.

" no leading zero bits " , ooh , not that isnt as easy

but anyway , didnt take ANY HINTS , no leetcode hints , no comments , no chatgpt hints
took out pen and paper and visualised and came up with this solution completely on my own - 

```java
class Solution {
    public int findComplement(int num) {
        boolean binaryStarted = false;
        for (int i =31;i>=0;i--) {
            int mask = 1 << i;
            int andResult = num & mask;
            if (andResult != 0) {
                binaryStarted = true;
            }
            if (binaryStarted) {
                    num = num ^ mask;
            }
        }
        return num;
    }
}
```
